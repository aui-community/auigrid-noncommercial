실행 및 라이선스 안내

"unauthorized hosts for AUIGrid" 메시지 안내

  • Case 1. 웹 서버에 올리지 않고 탐색기에서 index.html을 바로 실행한 경우입니다.
    반드시 웹 서버에 올린 후 http:// 또는 https://로 시작하는 URL로 접속하십시오.
  • Case 2. 구매한 정품 라이선스의 접속 도메인 또는 접속 IP가 아닌 곳에서 AUIGrid를 실행하는 경우입니다.
  • Case 3. 테스트 임시 라이선스를 신청한 경우, 해당 접속 도메인 또는 접속 IP가 아닌 곳에서 AUIGrid를 실행하는 경우입니다.
