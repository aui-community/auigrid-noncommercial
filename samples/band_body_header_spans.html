밴드형 바디에서 헤더의 colSpan과 rowSpan으로 가로, 세로 및 블럭 병합을 구성할 수 있습니다. 상위 및 하위 2×2 블럭, 1×2 세로 병합과 2×1 가로 병합을 함께 비교할 수 있습니다.

헤더 병합은 데이터 셀의 계층과 높이를 변경하지 않습니다. 밴드형에서는 bodyCell: true인 상위 칼럼의 값도 출력하며, 값이 있는 그룹 헤더를 눌러 정렬할 수 있습니다. 

// 칼럼 레이아웃에서 병합할 헤더에 지정합니다.
{ headerText: "블럭 병합", colSpan: 2, rowSpan: 2, children: [...] }
{ headerText: "세로 병합", rowSpan: 2, children: [...] }
{ dataField: "H", headerText: "가로 병합", colSpan: 2 }

체크를 해제하면 명시한 colSpan과 rowSpan만 제거하며 children으로 구성한 기본 그룹 헤더는 유지합니다.

현재 칼럼 레이아웃 보기

현재 getColumnLayout() 결과입니다. 병합 옵션이나 칼럼 순서를 변경하면 코드도 함께 갱신됩니다. colSpan과 rowSpan은 changeColumnLayout()으로 적용합니다.
