콤보박스와 드롭다운리스트의 차이점은 드롭다운리스트는 출력된 리스트 중 하나를 선택하는 반면 콤보박스는 출력된 리스트 중 하나를 선택하거나 직접 사용자가 다른 값을 입력 할 수 있습니다.

그룹과 하위 그룹 단계형 리스트를 작성해 상위 단계에 맞는 하위 단계 리스트를 지정할 수 있습니다.

■ Alt + 아래 화살표 키 : 리스트 열기

■ 아래 화살표 키 : 사용자가 글씨를 쓴 경우(또는 F2, 더블클릭 등의 편집 상태)에는 아래 화살표 키만 눌러도 리스트 열림

■ 위 또는 아래 화살표 키 : 리스트가 열린 경우, 위 아래로 선택 이동합니다. (Enter 적용, Esc 취소)

■ showEditorBtnOver 를 true 로 설정하면 마우스 오버 셀에 에디터 버튼이 따라 다닙니다.

"부서명(비동기)"에 인사부를 입력하고 Enter 또는 Tab으로 확정해 보십시오. 입력 중에는 조회하지 않으며 목록 버튼으로 열 때도 조회합니다. 비동기 목록은 자동완성을 지원하지 않습니다.

useAsyncHandler를 true로 설정하고 서버 응답을 0.6초 지연으로 모의 처리합니다. 대기 중 Esc로 취소할 수 있습니다.

비동기 칼럼 설정 코드 보기 
// 그리드 생성 속성: { editable: true, useAsyncHandler: true }
// 최초 데이터: { asyncDept: "002", asyncDeptName: "경영본부" }
{
    dataField: "asyncDept",
    displayField: "asyncDeptName", // useAsyncHandler: true에서 listFunction 사용 시 필수
    editRenderer: {
        type: "ComboBoxRenderer",
        keyField: "code",
        valueField: "value",
        listFunction: async function (rowIndex, columnIndex, item, dataField, value) {
            return await requestDepartments(value);
        }
    }
}

편집기는 코드만 저장합니다. 이 데모에서는 cellEditEnd 이후 updateRow로 표시 이름도 갱신합니다.
