드롭다운리스트는 미리 지정된 리스트 중 하나를 선택할 수 있는 에디트렌더러입니다.

그룹과 하위 그룹 단계형 드롭다운리스트를 작성해 상위 단계에 맞는 하위 단계 리스트를 지정할 수 있습니다.

■ Alt + 아래 화살표 키 : 드롭다운리스트 열기 (easyMode=false 설정한 경우는 아래 화살표 키 한번 더 필요)

■ editingOnKeyDown=true(기본값 true) 인 경우 SpaceBar 포함 어떤 키를 누르든 리스트 열림

■ 위 또는 아래 화살표 키 : 리스트가 열린 경우, 위 아래로 선택 이동합니다. (Enter 적용, Esc 취소)

■ showEditorBtnOver 를 true 로 설정하면 마우스 오버 셀에 에디터 버튼이 따라 다닙니다.

"부서명(비동기)" 셀을 더블클릭하거나 F2 또는 목록 버튼을 누르면 listFunction으로 부서 목록을 조회합니다.

useAsyncHandler를 true로 설정하고 서버 응답을 0.6초 지연으로 모의 처리합니다. 대기 중 Esc로 취소할 수 있습니다.

비동기 칼럼 설정 코드 보기 
// 그리드 생성 속성: { editable: true, useAsyncHandler: true }
// 최초 데이터: { asyncDept: "002", asyncDeptName: "경영본부" }
{
    dataField: "asyncDept",
    displayField: "asyncDeptName", // useAsyncHandler: true에서 listFunction 사용 시 필수
    editRenderer: {
        type: "DropDownListRenderer",
        keyField: "code",
        valueField: "value",
        listFunction: async function (rowIndex, columnIndex, item, dataField) {
            return await requestDepartments();
        }
    }
}

편집기는 코드만 저장합니다. 이 데모에서는 cellEditEnd 이후 updateRow로 표시 이름도 갱신합니다.
