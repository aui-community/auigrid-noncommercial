주문일의 연도, 월, 일 필터와 일반 값 목록을 비교해 보세요. 마지막 칼럼은 같은 날짜를 년, 월, 일 형식으로 표시합니다.

날짜별 메뉴는 dataType: "date"와 filter: { showIcon: true, type: "date" }로 설정합니다.

설정 코드 
{
    dataField: "formattedDate",
    dataType: "date", dateInputFormat: "yyyy-mm-dd", formatString: "yyyy년 mm월 dd일",
    filter: { showIcon: true, type: "date" }
}
