keepViewOnAdd: true로 행 추가 후에도 정렬과 필터를 유지합니다. 현재는 팀 A만 수량 내림차순으로 표시합니다.

A와 B를 추가하면 A만 보입니다. B도 원본에는 추가되므로 필터를 해제해 확인하세요. 체크를 끄면 기본 동작과 비교할 수 있습니다.

설정 코드 
const gridProps = { keepViewOnAdd: true, enableUndoRedo: true };
AUIGrid.addRow(myGridID, [
    { id: "B-new", team: "B", name: "새 담당자 B", qty: 30 },
    { id: "A-new", team: "A", name: "새 담당자 A", qty: 20 }
], "last");
