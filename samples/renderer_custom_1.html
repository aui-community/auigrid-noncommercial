"현재가" 칼럼은 그리드에서 제공되는 칼럼 렌더러가 아닌 사용자(개발자)가 직접 출력하고자 하는 칼럼 렌더러를 작성하여 설정한 모습입니다.

AUIGrid.js 다음에 렌더러 JS를 연결합니다.

<script src="../AUIGrid/renderers/AUIGrid.MyStockRenderer.js"></script>

렌더러 CSS는 이 페이지 상단의 <style>에 정의되어 있습니다. 소스 보기에서 해당 스타일을 함께 복사하십시오.

하나의 셀에 3개의 내용을 출력한 모습입니다.

사용자 렌더러는 다음과 같이 칼럼 렌더러에 "CustomRenderer" 를 type으로 지정하고, 실제 사용자가 작성한 js 파일을 jsClass 값으로 설정하십시오. 

dataField : "close",
headerText : "현재가",
width : 160,
renderer : {
	type : "CustomRenderer", // 사용자 정의 렌더러 사용
	jsClass : AUIGrid.MyStockRenderer // 작성한 사용자 정의 렌더러 JS
}

샘플로 제공되는 AUIGrid.MyStockRenderer.js 파일을 참고하여 원하는 렌더러를 작성해 보십시오.
