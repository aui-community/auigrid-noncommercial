배경색, 글자색 칼럼을 더블클릭하거나 선택 후 F2 / 스페이스바를 누르면 AUIGrid.RgbColorEditor가 열립니다.

RGB 슬라이더, 숫자, HEX 입력, 색상표로 고르고 Enter 또는 확인으로 적용, Esc 또는 취소로 닫습니다.

AUIGrid.js 다음에 편집기 JS와 편집기 CSS를 연결합니다. 칼럼의 editRenderer에 다음과 같이 지정합니다.

<script src="../AUIGrid/editRenderers/AUIGrid.RgbColorEditor.js"></script>
<link rel="stylesheet" href="../AUIGrid/editRenderers/AUIGrid.RgbColorEditor.css" />
editRenderer: {
    type: "CustomEditRenderer",
    jsClass: AUIGrid.RgbColorEditor,
    vPosition: "bottom",
    extraProps: {
        format: "rgb", // 생략하면 "hex"로 저장
        palette: ["#e53935", "#43a047", "#1e88e5"],
        confirm: "적용",
        cancel: "취소"
    }
}

저장 형식(extraProps.format)은 "hex"(#rrggbb, 기본값) 또는 "rgb"(rgb(r, g, b))입니다. 기존 값은 #rgb, #rrggbb 또는 rgb(r, g, b)를 사용합니다.

색상표(extraProps.palette)는 HEX 색상 배열이며 생략하면 기본 16색을 표시합니다. 버튼 문구(extraProps.confirm, extraProps.cancel)의 기본값은 "확인", "취소"입니다.

색상 셀을 편집해 보십시오.
