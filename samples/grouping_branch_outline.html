groupingBranchMode: "singleColumn"은 칼럼 순서를 유지하며 그룹 제목을 한 위치에서 들여 써 표시합니다.

밴드형 그룹핑은 singleColumn으로 표시합니다. 그룹 높이가 26px이면 소계를 수량 / 금액으로, 52px이면 수량 위와 금액 아래 두 줄로 표시합니다.

설정 코드
const gridProps = {
    bodyLayoutMode: "band", rowHeight: 90,
    groupingBranchMode: "singleColumn", groupingBranchHeight: 26,
    groupingFields: ["supplier", "category"],
    groupingSummary: { dataFields: ["orderQty", "orderAmount", "receivedQty", "receivedAmount"] },
    displaySummaryTreeBranch: true
};
