샘플 목록문서

MultiAutoCompleteRenderer로 목록을 검색하고 여러 항목을 선택하는 예제입니다.

Enter로 항목을 추가하고, 빈 입력란에서 Enter 또는 Tab으로 완료합니다. Esc는 취소합니다.

■ "ㅅㅈ"으로 "사장", "경영ㅂㅂ"으로 "경영본부"를 검색할 수 있습니다.

■ matchFromFirst: false이면 중간에 포함된 글자도 검색합니다. (부서명, 그룹 하위)

직급은 최대 3개, 컬러, 조건 리스트와 그룹은 1개까지 선택하며 최대 개수에 도달하면 자동 완료합니다. 나머지는 개수를 제한하지 않습니다.

직급은 뱃지로 표시하고 컬러는 목록 아이콘으로 편집합니다. 이름과 부서명은 표시 이름 대신 키를 저장합니다.

업무 (검증)는 2개 이상 선택해야 저장됩니다. 검증 실패 상태에서 그리드를 스크롤하면 편집을 취소하고 기존 값으로 돌아갑니다. 

{
    dataField: "tasks",
    headerText: "업무 (검증)",
    editRenderer: {
        type: "MultiAutoCompleteRenderer",
        list: ["기획", "개발", "검토", "운영"],
        validator: function (oldValue, newValue) {
            // 선택한 값은 구분자로 연결된 문자열로 전달됩니다.
            const values = newValue.split(",").map(value => value.trim()).filter(Boolean);
            return {validate: values.length >= 2, message: "업무를 2개 이상 선택해 주세요."};
        }
    }
}
