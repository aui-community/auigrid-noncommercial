화면 설정을 바꾸지 않고 Excel과 PDF 파일의 레이아웃만 원하는 형태(band, flat, flatAll)로 지정합니다.

내보내기 옵션의 bodyLayoutMode를 사용합니다. 생략하면 현재 화면의 레이아웃을 따릅니다. (v3.0.19부터 지원)

  • band: 상위 셀과 하위 셀을 밴드형으로 출력합니다.
  • flat: 그룹형 헤더를 유지하고 본문에는 최하위 칼럼만 출력합니다.
  • flatAll: dataField가 있는 상위 칼럼과 하위 칼럼을 독립된 열로 펼칩니다.

상단의 셀을 클릭하면 해당 사용자의 주문 상세가 하단에 표시됩니다. 두 그리드를 각각 다른 레이아웃으로 한 파일의 두 시트에 저장할 수 있습니다. 

// 그리드 하나를 독립된 열로 펼쳐 내보냅니다.
AUIGrid.exportToXlsx(myGridID, {
    fileName: "사용자_목록",
    bodyLayoutMode: "flatAll", // 현재 그리드 출력된 바디 레이아웃과 무관하게 전체 펼치기(flatAll)로 내보내기
    rowHeight: 30
});

// 각 그리드를 서로 다른 레이아웃의 시트로 내보냅니다.
AUIGrid.exportToXlsxMulti(myGridID, [myGridID2], [
    { fileName: "사용자_목록과_주문_상세", sheetName: "사용자 목록", bodyLayoutMode: "flatAll", rowHeight: 30 },
    { sheetName: "선택 사용자 주문 상세", bodyLayoutMode: "flat", rowHeight: 30 }
]);

// PDF도 같은 옵션으로 파일의 레이아웃만 지정합니다.
AUIGrid.exportToPdf(myGridID, {
    fileName: "사용자_목록",
    bodyLayoutMode: "flatAll", // 현재 그리드 출력된 바디 레이아웃과 무관하게 전체 펼치기(flatAll)로 내보내기
    rowHeight: 30,
    fontPath: "../pdfkit/nyjgothic-medium.ttf"
});
