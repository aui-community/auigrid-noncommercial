연속된 형제 그룹의 헤더를 colSpan: 4, rowSpan: 2로 하나의 블럭으로 병합합니다. 두 그룹의 자식 칼럼 A~D는 같은 위치에 유지됩니다.

colSpan은 그룹 개수가 아닌 최하위 칼럼 수입니다. 자신의 자식 전체를 포함하고 같은 부모 아래의 연속된 형제 그룹 경계에서 끝나도록 지정합니다. 

// 두 형제 그룹에 속한 A~D 헤더 영역을 하나로 병합합니다.
{ headerText: "형제 그룹 블럭 병합", colSpan: 4, rowSpan: 2,
  children: [{ dataField: "A" }, { dataField: "B" }] },
{ headerText: "두 번째 형제 그룹",
  children: [{ dataField: "C" }, { dataField: "D" }] }

체크를 해제하면 명시한 colSpan과 rowSpan만 제거하며 children으로 구성한 기본 그룹 헤더는 유지합니다.
