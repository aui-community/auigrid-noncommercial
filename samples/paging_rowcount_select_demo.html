페이징 모드에서 showPageRowSelect로 페이지당 행 개수 선택 UI를 표시하고, pageRowSelectValues로 선택할 값을 지정합니다.

그리드 하단에서 20, 40, 60, 80, 100개 중 하나를 선택하세요. pageRowCountChange 이벤트의 변경 전후 행 개수와 전체 페이지 수를 그리드 아래에서 확인할 수 있습니다. 

// 페이지 행 개수 select UI 출력 여부 (기본값 : false)
showPageRowSelect : true,
		
// select UI 에 출력 시킬 옵션값들 (기본값 : [10, 20, 30, 40, 50])
pageRowSelectValues : [20, 40, 60 , 80, 100]
