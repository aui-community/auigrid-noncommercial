사용자 정의 렌더러로 날짜와 목표 달성률을 표시한 달력입니다.

AUIGrid.js 다음에 렌더러 JS와 CSS를 연결합니다.

<script src="../AUIGrid/renderers/AUIGrid.MyCalendarRenderer.js"></script>
<link rel="stylesheet" href="../AUIGrid/renderers/AUIGrid.MyCalendarRenderer.css" />

칼럼의 renderer에 type과 jsClass를 다음과 같이 지정합니다.

{
    dataField: "0",
    headerText: "일",
    minWidth: 72,
    renderer: {
        type: "CustomRenderer", // 사용자 정의 렌더러 사용
        jsClass: AUIGrid.MyCalendarRenderer // 작성한 사용자 정의 렌더러 JS
    }
}

샘플로 제공되는 AUIGrid.MyCalendarRenderer.js 파일을 참고하여 원하는 렌더러를 작성해 보십시오.
