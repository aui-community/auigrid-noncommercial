스파크 차트, 스위치, 바 게이지의 height를 행 높이와 별도로 지정합니다. 높이를 바꾸어 비교하세요.

높이를 생략하거나 NaN으로 지정하면 기본 크기를 사용합니다.

설정 코드 
const gridProps = { rowHeight: 90, wordWrap: true };
const column = {
    dataField: "enabled",
    renderer: { type: "SwitchRenderer", height: 30, editable: true }
};
// 생성 후에도 칼럼 인덱스 4의 스위치 높이를 변경할 수 있습니다.
AUIGrid.setRendererProp(myGridID, 4, { height: 50 });
