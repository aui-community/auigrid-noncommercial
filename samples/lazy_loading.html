이 패키지는 별도의 데이터 서버 없이 포함된 예제 데이터로 조회, 검색 및 페이지 이동을 시연합니다. 웹 서버의 HTTP(S) 주소로 실행하고, 실제 프로젝트에서는 데이터 요청 부분을 서버 API에 연결하십시오.

최초에 그리드에 적은 데이터를 삽입한 후 수직 스크롤이 최하단에 간 경우 추가 요청하여 기존 그리드 데이터에 붙입니다.(appendData)

그리드가 그룹핑이 된 경우 추가로 붙여진 그리드를 포함하여 다시 그룹핑을 하고, 합계 필드(SummaryFields) 및 푸터 연산을 계산 합니다.

데모는 최초 100개의 데이터를 기본 출력하고, 수직 스크롤이 최하단에 온 경우 20개의 데이터를 요청하여 추가시킵니다.

데모 서버 부하를 줄이기 위해 추가 데이터 요청은 최대 10회로 제한합니다.

그리드를 선택한 후 "Ctrl + 아래 화살표 방향키"를 누르면 마지막 행으로 이동합니다. macOS에서는 Ctrl 대신 Command 키를 사용합니다.
