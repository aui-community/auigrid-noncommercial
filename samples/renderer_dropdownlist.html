DropDownList 렌더러는 미리 지정된 리스트 안에서 하나를 선택할 수 있는 렌더러입니다.

칼럼 레이아웃 정의 시 renderer 의 속성의 type 으로 DropDownListRenderer 를 설정한 모습입니다.

renderer 의 속성 type 으로 정의하면 바로 편집 가능한 DropDownList 가 출력됩니다.

그룹과 하위 그룹 단계형 드롭다운리스트를 작성해 상위 단계에 맞는 하위 단계 리스트를 지정할 수 있습니다.

■ "직급" 칼럼과 같이 드롭다운리스트를 셀에 바로 작성할 수 있습니다.

■ "부서명" 칼럼은 드롭다운리스트를 key-value 를 갖는 Object 리스트를 출력한 모습입니다.

■ "그룹, 하위그룹" 칼럼은 관련성을 갖는 구조로 작성된 모습입니다.

"부서명(비동기)"은 useAsyncHandler를 true로 설정하고 listFunction의 응답을 기다립니다. keyField는 저장 코드, valueField는 목록의 이름입니다. 셀은 처음부터 displayField의 값을 표시하고, 목록을 열 때만 조회합니다.

목록 응답은 0.6초 지연으로 모의 처리합니다. 선택한 항목의 code와 value를 dataField와 displayField에 함께 저장합니다.

비동기 칼럼 설정 코드 보기 
// 그리드 생성 속성: { useAsyncHandler: true }
{
    dataField: "asyncDept",
    displayField: "asyncDeptName", // 비동기 key-value 목록의 표시 이름을 저장할 필드 (필수)
    renderer: {
        type: "DropDownListRenderer",
        keyField: "code",
        valueField: "value",
        listFunction: async function (rowIndex, columnIndex, item, dataField) {
            return await requestDepartments();
        }
    }
}
