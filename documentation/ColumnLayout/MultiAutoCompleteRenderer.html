MultiAutoCompleteRenderer

목록을 검색하여 여러 항목을 선택하는 자동완성 편집 렌더러입니다. 한글 초성 검색과 부분 검색을 지원하며 영문 대소문자를 구분하지 않습니다.

칼럼 레이아웃의 editRenderer 속성에 Object 형태로 선언합니다. 칼럼의 editRenderer 속성의 type으로만 설정 가능합니다.

선택한 항목은 편집기 안에서 태그로 표시하며, 변경한 값은 delimiter로 연결한 문자열로 저장합니다. 편집이 끝난 셀의 표시 방식은 칼럼의 renderer, labelFunction 또는 displayField에서 지정합니다.

항목을 클릭하거나 방향키와 Enter로 선택하고 Tab으로 편집을 완료합니다. 입력과 목록의 선택 강조가 없을 때 Enter를 누르거나 그리드 바깥을 클릭해도 완료합니다. Esc로 취소하며 태그의 × 버튼이나 빈 입력란의 Backspace로 선택을 제거합니다.

관련 데모 보기

아래는 설정 예제 입니다. 
const columnLayout = [{
    dataField: "tasks",
    headerText: "업무",
    width: 180,
    editRenderer: {
        type: "MultiAutoCompleteRenderer",
        list: ["기획", "개발", "검토", "운영"],
        maxItemCount: 3 // 3개를 선택하면 편집을 완료합니다.
    }
}];
// 기획과 개발을 선택하면 "기획, 개발"로 저장합니다.
Name Description
allowCustomValue
Type : Boolean   Version: 3.0.20

목록에 없는 값을 직접 입력하여 추가할지 지정합니다. true이면 일치하는 추천 항목이 없을 때 Enter로 입력값을 추가합니다. 객체 목록에서도 입력 문자열을 그대로 키로 저장합니다.

관련 데모 보기

기본값(default) : false
delimiter
Type : String   Version: 3.0.20

선택한 값을 연결하여 저장할 구분자를 지정합니다. 기존 값은 문자열 또는 배열로 지정할 수 있으며, 선택을 변경하지 않으면 원본 값을 유지합니다.

기존 문자열은 이 구분자의 앞뒤 공백을 제거한 값으로 나눕니다. 저장할 값이나 객체 목록의 키에는 구분자를 포함하지 마십시오. 빈 문자열을 지정하면 기본값을 사용합니다. 

editRenderer: {
    type: "MultiAutoCompleteRenderer",
    list: ["기획", "개발", "검토"],
    delimiter: "; " // 기획과 개발을 선택하면 "기획; 개발"로 저장합니다.
}

관련 데모 보기

기본값(default) : ", "
descendantDefaultValues
Type : Array   Version: 3.0.20

descendants로 연결한 하위 칼럼에 적용할 초기값을 배열로 지정합니다. 하위 칼럼과 같은 순서로 작성하며, 부모 값이 바뀌면 함께 적용합니다. 지정하지 않으면 하위 칼럼의 값을 유지합니다.

관련 데모 보기

기본값(default) : null
descendants
Type : Array   Version: 3.0.20

값을 변경할 때 함께 초기화할 하위 칼럼의 dataField를 배열로 지정합니다. descendantDefaultValues에 같은 순서로 초기값을 설정합니다. 

editRenderer: {
    type: "MultiAutoCompleteRenderer",
    list: ["A", "B", "C"],
    maxItemCount: 1,
    descendants: ["subGroup"],
    descendantDefaultValues: ["-"] // 그룹을 바꾸면 하위 그룹을 초기화합니다.
}

관련 데모 보기

기본값(default) : null
keyField
Type : String   Version: 3.0.20

목록 항목이 객체인 경우 실제 데이터에 저장할 키의 필드명을 지정합니다. 표시 이름의 필드인 valueField와 함께 설정합니다.

문자열과 숫자 키를 사용할 수 있으며, 문자열로 변환하여 저장하고 비교합니다. 숫자 0과 문자열 "0"은 같은 키로 처리합니다. 

editRenderer: {
    type: "MultiAutoCompleteRenderer",
    keyField: "code",
    valueField: "name",
    list: [
        { code: "DEV", name: "개발팀" },
        { code: "QA", name: "품질관리팀" }
    ]
}
// 두 항목을 선택하면 "DEV, QA"로 저장합니다.

관련 데모 보기

기본값(default) : null
list
Type : Array   Version: 3.0.20

선택 목록에 표시할 문자열 배열을 지정합니다. 객체 배열은 keyField와 valueField를 함께 설정하여 사용합니다. listFunction을 지정하면 해당 함수가 반환한 목록을 사용합니다.

검색어가 없으면 선택하지 않은 전체 목록을 표시합니다. 빈 키는 제외하고 중복 키는 첫 항목만 사용합니다.

관련 데모 보기

기본값(default) : []
listAlign
Type : String   Version: 3.0.20

목록 항목의 텍스트 정렬을 지정합니다. "left"는 왼쪽, "center"는 가운데, "right"는 오른쪽 정렬입니다.

관련 데모 보기

기본값(default) : "center"
listFunction
Type : Function   Version: 3.0.20

편집을 시작할 때 선택 목록을 반환하는 함수를 지정합니다. list보다 우선하며 편집 시작 시 한 번 호출합니다.

함수의 파라메터는 다음과 같습니다.

  • rowIndex : 행 인덱스
  • columnIndex : 칼럼 인덱스
  • item : 해당 행의 데이터 객체
  • dataField : 해당 칼럼의 데이터 필드명

반환값은 문자열 또는 객체 배열입니다. useAsyncHandler=true여도 async 함수와 Promise 반환은 지원하지 않습니다. 

listFunction: function (rowIndex, columnIndex, item, dataField) {
    // 같은 행의 그룹에 맞는 하위 목록을 반환합니다.
    return item.group === "A" ? ["A-1", "A-2"] : ["B-1", "B-2"];
}

관련 데모 보기

기본값(default) : null
listHeight
Type : Number   Version: 3.0.20

선택 목록의 최대 높이를 픽셀 단위로 지정합니다. 생략하면 기본 CSS의 200px 제한을 사용하며, 목록이 더 길면 세로 스크롤을 표시합니다. 검색 입력란과 선택 태그의 높이는 포함하지 않습니다.

관련 데모 보기

기본값(default) : NaN
listTemplateFunction
Type : Function   Version: 3.0.20

목록 항목에 표시할 HTML 문자열을 반환하는 함수를 지정합니다. 항목에 이미지나 추가 정보를 함께 표시할 때 사용합니다.

함수의 파라메터는 다음과 같습니다.

  • rowIndex : 행 인덱스
  • columnIndex : 칼럼 인덱스
  • text : 목록 항목의 표시 이름
  • item : 해당 행의 데이터 객체
  • dataField : 해당 칼럼의 데이터 필드명
  • listItem : 원본 목록 항목(문자열 또는 객체)
listTemplateFunction: function (rowIndex, columnIndex, text, item, dataField, listItem) {
    // 미리 정의한 목록 항목에 아이콘을 함께 표시합니다.
    return '<span aria-hidden="true">&#9733;</span> ' + text;
}

반환한 HTML은 추천 목록에만 적용합니다. 객체 목록의 검색과 선택 태그는 valueField의 값을 사용합니다.

관련 데모 보기

기본값(default) : null
matchFromFirst
Type : Boolean   Version: 3.0.20

입력한 내용이 항목의 시작 부분과 일치해야 하는지 지정합니다. false이면 입력 내용을 포함하는 항목을 표시합니다. 한글 초성 검색에도 같은 기준을 적용합니다.

관련 데모 보기

기본값(default) : false
maxItemCount
Type : Number   Version: 3.0.20

최대 선택 개수를 지정합니다. 0이면 제한하지 않습니다. 사용자가 항목을 선택하여 최대 개수에 도달하면 편집을 자동으로 완료하며, validator가 있으면 검증 후 적용합니다.

1로 설정하면 편집 시작 시 기존 선택을 비우고 전체 목록을 표시합니다. 새 항목을 선택하지 않거나 Esc로 취소하면 기존 값을 유지합니다. 이 속성으로 기존 데이터를 잘라내지는 않습니다.

기본값(default) : false
validator
Type : Function   Version: 3.0.20

편집한 값을 실제 데이터에 적용하기 전에 유효성을 검사하는 함수를 지정합니다. Tab, Enter 또는 최대 선택 개수 도달 등 편집을 완료할 때 실행하며, 선택을 추가하거나 제거할 때마다 실행하지는 않습니다.

함수의 파라메터는 다음과 같습니다.

  • oldValue : 수정 전 셀 값
  • newValue : 적용할 선택값. 객체 목록은 표시 이름이 아닌 키
  • item : 해당 행의 데이터 객체
  • dataField : 해당 칼럼의 데이터 필드명
  • fromClipboard : 붙여넣기로 값을 수정하는지 여부
  • which : 편집 완료 방식(String 또는 Number)

반환 객체의 validate가 true이면 적용하고, false이면 편집을 유지하며 message를 표시합니다. 실패 시 initValue를 지정하면 해당 값으로 선택을 복원합니다. 검증 실패 상태에서 그리드를 가로나 세로로 스크롤하면 편집을 취소하고 기존 값을 유지합니다. 

validator: function (oldValue, newValue, item, dataField, fromClipboard, which) {
    // 기본 구분자로 저장하는 업무를 2개 이상 선택했는지 확인합니다.
    const values = String(newValue || "").split(",").filter(function (value) {
        return value.trim() !== "";
    });
    return { validate: values.length >= 2, message: "업무를 2개 이상 선택해 주세요." };
}

useAsyncHandler=true이면 async 함수 또는 Promise로 검증 결과를 반환할 수 있습니다. 대기 중 Esc로 취소할 수 있습니다. 붙여넣기의 검증 실패 시에는 메시지를 표시하지 않습니다.
