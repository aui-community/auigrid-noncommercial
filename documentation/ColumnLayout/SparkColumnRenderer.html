SparkColumnRenderer

셀 안에 스파크 칼럼 차트를 표시하는 렌더러입니다. 여러 값의 크기를 작은 막대 차트로 보여 줄 때 사용합니다.

스파크 칼럼 렌더러에 출력 시킬 데이터 설정은 dataField 속성에 컴마(,) 구분자를 사용한 복수의 데이터필드를 설정하십시오.

스파크 칼럼 렌더러는 칼럼 레이아웃을 정의할 때 개별 칼럼의 renderer 속성 값인 Object 형태로 선언되어야 합니다.

canvas 를 지원하는 브라우저에서 사용 가능합니다.(IE 인 경우 9 이상)

칼럼의 renderer 속성의 type 으로만 설정 가능합니다.

아래는 설정 예제 입니다. 

const columnLayout = [{
     dataField : "name",
     headerText : "Name",
     width : 140
}, {
     dataField : "m1,m2,m3,m4,m5",
     headerText : "SparkChart",
     width : 120,
     renderer : {
            type : "SparkColumnRenderer",
            markMaxValue : true,
            maxColor : "#ff0000"
      }
}];

height
Type : Number   Version: 3.0.18

렌더러 표시 영역의 높이를 픽셀 단위로 지정합니다.

양수를 지정하며 기본값 NaN이면 행 높이에 맞춥니다. wordWrap이 true이면 지정한 높이를 행 높이 계산에 반영합니다.

renderer: {
    type: "SparkColumnRenderer",
    height: 30 // 표시 영역의 높이
}

Also See : setRendererProp()

renderingField
Type : String

특정 행에만 스파크 차트를 표시할 때 기준으로 사용할 필드를 지정합니다.

renderingField 를 정의 한 후 해당 Row 데이터에 정의한 필드가 true 인 경우만 스파크 차트가 출력됩니다.

예를 들어 칼럼 레이아웃에서 renderingField : "drawSpark" 라고 정의 하고, 데이터 작성 시(JSON 또는 XML) 특정 Row 에 drawSpark : true ( <drawSpark>true</drawSpark> ) 를 설정하면 drawSpark 가 true 로 지정된 데이터의 행만 스파크 차트가 출력됩니다.
