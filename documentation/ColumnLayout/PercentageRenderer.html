PercentageRenderer

숫자 비율을 막대와 백분율로 표시하는 렌더러입니다. 예를 들어 데이터가 0.815이고 precision이 1이면 81.5%로 표시합니다.

백분율 렌더러는 칼럼 레이아웃을 정의할 때 개별 칼럼의 renderer 속성 값인 Object 형태로 선언되어야 합니다.

칼럼의 renderer 속성의 type 으로만 설정 가능합니다.

백분율을 입력하여 수정하려면 PercentageEditRenderer를 함께 사용합니다.

숫자와 숫자로 변환할 수 있는 문자열을 표시하며, 빈 값이나 음수 등 유효하지 않은 값은 표시하지 않습니다. 0은 0%로, 1을 초과하는 값은 가득 찬 막대와 실제 백분율로 표시합니다.

출력 형식은 백분율로 고정됩니다. 소수 자릿수는 precision으로 지정하며 칼럼의 labelFunction, formatString, prefix 및 postfix는 적용하지 않습니다.

Excel 내보내기에서는 원본 비율을 숫자로 저장하고 백분율 서식과 그라데이션 데이터 막대를 적용합니다. PDF는 화면의 막대와 라벨 설정을 반영합니다.

관련 데모 보기

아래는 설정 예제 입니다. 
const columnLayout = [{
    dataField: "progress",
    headerText: "진행률",
    width: 200,
    renderer: {
        type: "PercentageRenderer",
        precision: 1,
        labelPosition: "center", // 막대 가운데에 백분율 표시
        barHeight: 20
    }
}];
Name Description
barHeight
Type : Number   Version: 3.0.20

막대의 높이를 픽셀 단위로 지정합니다. 생략하거나 유효하지 않은 값이면 테마의 높이(기본 8px)를 사용합니다.

0 이상의 유한한 숫자를 사용하며 렌더러 표시 영역보다 크게 지정하면 영역 높이로 제한합니다. 0이면 막대만 보이지 않고 라벨은 showLabel을 따릅니다. 행 높이는 바뀌지 않습니다.

PDF에도 적용되며 출력 셀 높이로 제한됩니다. Excel 데이터 막대의 높이에는 적용하지 않습니다.

기본값(default) : NaN
height
Type : Number   Version: 3.0.19

렌더러 표시 영역의 높이를 픽셀 단위로 지정합니다. 생략하면 셀 높이에 맞추며 막대와 라벨은 세로 가운데에 배치합니다.

기본값(default) : NaN
labelPosition
Type : String   Version: 3.0.20

막대와 백분율 텍스트를 함께 표시할 때 텍스트의 위치를 지정합니다.

"right"는 막대 오른쪽에 표시합니다. "center"는 셀 전체 폭을 사용하는 막대의 가운데에 겹쳐 표시하며 offset을 적용하지 않습니다.

Excel과 PDF에도 적용됩니다. Excel에 별도로 지정한 exportStyle의 textAlign이 있으면 해당 정렬을 우선합니다.

기본값(default) : "right"
offset
Type : Number   Version: 3.0.19

막대와 오른쪽 백분율 텍스트 사이의 간격을 픽셀 단위로 지정합니다. showBar와 showLabel이 모두 true이고 labelPosition이 "right"일 때 적용합니다.

0 이상의 유한한 숫자를 사용하며 생략하거나 유효하지 않은 값이면 기본값 0을 사용합니다.

기본값(default) : 0
precision
Type : Number   Version: 3.0.19

백분율의 소수 자릿수를 0~6의 정수로 지정합니다. 예를 들어 0.815에 1을 지정하면 81.5%로 표시합니다.

소수인 설정값은 버림하고 범위를 벗어나면 0~6으로 제한합니다. 유효하지 않은 값은 0을 사용합니다. 막대 길이와 styleRange는 반올림 전 비율을 사용합니다.

기본값(default) : 0
showBar
Type : Boolean   Version: 3.0.19

막대 그래프를 표시할지 지정합니다. false이면 showLabel을 true로 처리하여 백분율 텍스트만 표시하며, 텍스트 정렬은 칼럼 스타일을 따릅니다.

Excel 내보내기에서도 false이면 막대를 제외하고 숫자와 백분율 서식은 유지합니다. xlsxTextConversion: true이면 백분율 문자열만 저장합니다.

exportWithStyle: false이면 백분율 서식을 제외하며, showBar가 true이면 기본 색상의 데이터 막대를 사용합니다.

기본값(default) : true
showLabel
Type : Boolean   Version: 3.0.19

백분율 텍스트를 표시할지 지정합니다. 막대와 함께 표시할 때의 위치는 labelPosition으로 설정합니다.

showBar가 false이면 이 값을 false로 지정해도 텍스트를 표시합니다. PDF에도 같은 표시 규칙을 적용하며, 복사와 Excel 및 CSV 내보내기의 백분율 값에는 영향을 주지 않습니다.

기본값(default) : true
style
Type : String   Version: 3.0.19

렌더러에 적용할 CSS 클래스 이름을 지정합니다. styleRange의 구간 클래스와 함께 적용됩니다.

.aui-grid-percentage-track은 막대 배경, .aui-grid-percentage-bar는 채워진 막대, .aui-grid-percentage-label은 백분율 텍스트입니다. 

.progress-style .aui-grid-percentage-bar { background: #18825d; }
.progress-style .aui-grid-percentage-label { color: #166549; }

Excel은 내보내기 시점의 막대 색상을 사용하며 파일에서 값을 수정해도 구간 색상을 다시 판정하지 않습니다. PDF는 막대 배경과 채움, 라벨 색상을 반영합니다.

기본값(default) : null
styleRange
Type : Array   Version: 3.0.19

값의 구간에 따라 적용할 CSS 클래스 이름을 지정합니다. 각 항목에 상한 비율과 클래스 이름을 하나씩 넣고, 0~1의 상한을 오름차순으로 작성합니다.

각 구간은 이전 상한 초과부터 현재 상한까지입니다. 첫 구간에는 0을 포함하며 1을 초과하는 데이터는 1로 판정합니다. 해당 구간이 없거나 클래스 이름이 빈 문자열이면 기본 스타일을 사용합니다. 

styleRange: [
    { "0.3": "progress-low" },      // 0~30%
    { "0.5": "progress-medium" },   // 30% 초과~50%
    { "1": "progress-complete" }   // 50% 초과, 100% 초과 포함
]

상한이 0~1의 숫자가 아니거나 오름차순을 지키지 않은 항목, 상한이 여러 개인 항목, 클래스 이름이 문자열이 아닌 항목은 무시합니다.

기본값(default) : null
