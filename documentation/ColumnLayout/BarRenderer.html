BarRenderer

셀의 값을 바 게이지로 표시하는 렌더러입니다.

바 렌더러는 칼럼 레이아웃을 정의할 때 개별 칼럼의 renderer 속성 값인 Object 형태로 선언되어야 합니다.

칼럼의 renderer 속성의 type 으로만 설정 가능합니다.

아래는 설정 예제 입니다. 

const columnLayout = [{
     dataField : "name",
     headerText : "Name",
     width : 140
}, {
     dataField : "quantity",
     headerText : "Quantity",
     width : 120,
     renderer : {
            type : "BarRenderer",
            min : -100,
            max : 100,
            offset : 40
      }
}];
NameDescription
height
Type : Number   Version: 3.0.18

렌더러 표시 영역의 높이를 픽셀 단위로 지정합니다.

양수를 지정하며 기본값 NaN이면 행 높이에 맞춥니다. wordWrap이 true이면 지정한 높이를 행 높이 계산에 반영합니다.

renderer: {
    type: "BarRenderer",
    height: 30 // 표시 영역의 높이
}

Also See : setRendererProp()

관련 데모 보기

기본값(default) : 0
offset
Type : Number

바 게이지에 표시되는 텍스트의 좌우 여백을 지정합니다.

기본적으로 칼럼 전체의 text-align 스타일을 따릅니다. 그러나 min, max 가 -100 ~ 100 사이 인 경우(즉, 0이라는 기준점이 있는 경우) 게이지의 시작은 0 에서 음수와 양수 범위로 나뉘어 출력되고, 텍스트는 가운데 출력이 됩니다.

이 때 텍스트의 좌우 여백을 지정하여 좀 더 자연스러운 텍스트를 출력할 수 있습니다.
