PercentageEditRenderer

백분율 숫자를 입력하여 값을 수정하는 편집 렌더러입니다. 데이터가 0.1이면 입력창에 10을 표시하고, 20을 입력하면 0.2를 저장합니다. % 기호 없이 숫자만 입력합니다.

백분율 편집 렌더러는 칼럼 레이아웃을 정의할 때 개별 칼럼의 editRenderer 속성 값인 Object 형태로 선언되어야 합니다.

칼럼의 editRenderer 속성의 type 으로만 설정 가능합니다.

화면 표시는 PercentageRenderer를 함께 사용합니다.

입력창의 값만 백분율에서 원본 비율로 변환합니다. setCellValue 등의 API와 셀에 직접 붙여넣는 값은 원본 비율 단위를 사용합니다. 편집 이벤트에도 원본 비율을 전달합니다.

PercentageRenderer의 precision은 표시용이며 입력값을 반올림하지 않습니다. 빈 값의 저장 방식은 그리드의 blankNumericToNullOnEditing 및 blankToNullOnEditing 설정을 따릅니다.

관련 데모 보기

아래는 설정 예제 입니다. 
const columnLayout = [{
    dataField: "progress",
    headerText: "진행률",
    dataType: "numeric",
    renderer: { type: "PercentageRenderer", precision: 1 },
    editRenderer: {
        type: "PercentageEditRenderer",
        max: 100 // 100%까지 입력하며 원본 비율은 최대 1로 저장
    }
}];
Name Description
allowPoint
Type : Boolean   Version: 3.0.19

소수점 입력을 허용할지 지정합니다. false이면 백분율 숫자의 정수 부분만 사용합니다.

기존 소수 값과 셀 붙여넣기도 편집 확정 시 소수 부분을 버립니다. 이때 min은 올림, max는 버림하여 정수 범위를 적용합니다.

기본값(default) : true
inputMode
Type : String   Version: 3.0.19

모바일 가상 키보드의 형식을 지정합니다. 유효값은 "text", "decimal", "numeric", "tel", "search", "email", "url", "none"입니다.

생략하면 allowPoint가 true일 때 "decimal", false일 때 "numeric"을 사용합니다. 실제 키보드 형태는 기기에 따라 다릅니다.

기본값(default) : "decimal"
max
Type : Number   Version: 3.0.19

입력할 백분율 숫자의 최댓값을 지정합니다. 예를 들어 100이면 100%까지 입력하며 원본 비율의 상한은 1입니다.

입력하거나 붙여넣은 값이 상한을 넘으면 즉시 보정합니다. 생략하거나 0 이상의 유한한 숫자가 아니면 상한을 제한하지 않으며, min보다 작은 설정도 무시합니다.

기본값(default) : null
maxlength
Type : Number   Version: 3.0.19

입력할 수 있는 최대 글자 수를 지정합니다. 소수점도 글자 수에 포함하며, 숫자의 최댓값은 max로 지정합니다.

기본값(default) : 10000
min
Type : Number   Version: 3.0.19

입력할 백분율 숫자의 최솟값을 지정합니다. 예를 들어 20이면 편집 완료 시 20% 미만의 값을 20%(원본 비율 0.2)로 보정합니다.

입력 중에는 하한 미만의 값을 허용합니다. 생략하거나 0 이상의 유한한 숫자가 아니면 0을 사용하며 음수 입력은 허용하지 않습니다.

기본값(default) : 0
notCheckByClipboard
Type : Boolean   Version: 3.0.19

셀에 직접 붙여넣을 때 숫자, allowPoint, min, max 및 validator 검사를 생략할지 지정합니다. true이면 붙여넣은 원본 비율을 그대로 사용합니다.

기본값(default) : false
textAlign
Type : String   Version: 3.0.19

편집기 입력란의 텍스트 정렬을 지정합니다. 유효값은 "left", "right", "center"입니다.

기본값(default) : "right"
validator
Type : Function   Version: 3.0.19

입력한 값을 실제 데이터에 적용하기 전에 유효성을 검사하는 함수를 지정합니다.

oldValue와 newValue는 원본 비율이며 newValue에는 min과 max가 먼저 적용됩니다. 예를 들어 20을 입력하면 newValue는 0.2입니다.

파라미터 설명

  • oldValue, newValue: 수정 전과 수정 후의 원본 비율
  • item, dataField: 행 데이터와 칼럼의 데이터 필드명
  • fromClipboard: 셀 붙여넣기인 경우 true
  • which: 편집 완료 키 또는 경로

검사 결과는 { validate, message } 객체로 반환합니다. validate가 false이면 수정을 거부하고 message를 안내합니다. 거부 시 원래 값으로 되돌리며, initValue를 반환하면 해당 비율을 입력창에 백분율로 표시합니다. 

validator: function (oldValue, newValue, item, dataField, fromClipboard, which) {
    // 원본 비율을 기준으로 100% 이하인지 검사합니다.
    return { validate: newValue <= 1, message: "100% 이하로 입력하세요." };
}

v3.0.20부터 useAsyncHandler를 true로 설정하면 async 함수 또는 Promise로 검증 결과를 반환할 수 있습니다. { validate: true }이면 완료하고, { validate: false, message, initValue }이면 기존 검증 실패 처리를 따릅니다. 입력기에서는 편집을 유지하며 initValue로 입력값을 복원합니다. Promise가 거부되면 검증 실패 안내를 표시합니다.

대기 중에는 값과 선택을 유지하며 Esc로 취소할 수 있습니다. API로 데이터나 구조 등을 교체한 뒤 도착한 결과는 무시합니다. 붙여넣기는 셀 순서대로 기다리고 validate:false인 셀을 건너뜁니다. 거부된 Promise는 진행 중인 붙여넣기를 중단하며 이미 완료한 셀은 유지합니다. notCheckByClipboard 등 기존 검증 실행 조건은 같습니다.

기본값(default) : null
