NumberStepRenderer

숫자 입력란과 증가, 감소 버튼으로 값을 편집하는 렌더러입니다. 칼럼의 renderer 또는 editRenderer로 사용할 수 있습니다.

넘버스텝 렌더러는 칼럼 레이아웃을 정의할 때 개별 칼럼의 renderer, editRenderer 속성 값인 Object 형태로 선언되어야 합니다.

칼럼의 editRenderer 와 renderer 속성의 type 모두 설정 가능합니다.

아래는 설정 예제 입니다. 

const columnLayout = [{
     dataField : "name",
     headerText : "Name",
     width : 140
}, {
     dataField : "Price",
     headerText : "price",
     width : 120,
     renderer : {
            type : "NumberStepRenderer",
            min : 0,
            max : 200000,
            step : 100,
            textEditable : false
      }
}];

inputMode
Type : String   Version: 3.0.11

모바일 기기 등에 표시할 가상 키보드의 형식을 지정합니다. 실제 키보드의 형태와 지원 여부는 사용하는 기기에 따라 달라집니다.

유효값은 다음과 같습니다.

  • text : 사용자의 현재 로케일에 맞는 표준 키보드를 제공합니다.
  • decimal : 사용자의 로케일에 맞는 숫자형 키보드를 제공합니다. 기기에 따라 음의 부호(-)는 제공할 수도, 제공하지 않을 수도 있습니다.
  • numeric : 숫자형 키보드를 제공합니다.
  • tel :전화번호 키보드를 제공합니다.
  • search : 검색 입력 칸에 최적화한 가상 키보드를 제공합니다.
  • email : 이메일 입력에 최적화한 가상 키보드를 제공합니다.
  • url : URL 입력에 최적화한 가상 키보드를 제공합니다.
  • none : 가상 키보드를 출력하지 않습니다.

sensitivity
Type : Number   Version: 3.0.11.10

증가, 감소 버튼을 계속 누르고 있을 때 값이 반복해서 변하는 간격을 밀리초(ms) 단위로 지정합니다.

버튼을 누르면 즉시 한 번 변경하며, 400ms 동안 누르고 있으면 반복을 시작합니다. 예를 들어 300으로 설정하면 이후 0.3초마다 변경됩니다. 최소 간격은 100ms입니다.
