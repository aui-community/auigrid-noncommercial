AUIGrid v3.0.20 Documentation

설치와 데이터 구성부터 칼럼 설정, API 활용까지 AUIGrid 개발에 필요한 내용을 확인할 수 있습니다.

AUIGrid

문서 살펴보기

  1. AUIGrid 소개 및 사용 방법제품 구성과 설치 방법을 확인할 수 있습니다.
  2. 데이터 구조 및 작성 방법에 대하여그리드에 사용할 데이터 구조를 알아볼 수 있습니다.
  3. 간단하게 그리드 생성해 보기(Quick Start)예제 코드로 첫 그리드를 만들어 볼 수 있습니다.
  4. 칼럼 레이아웃(Column Layout) 설정에 대하여칼럼 구성과 셀 표시 방법을 설정할 수 있습니다.
  5. 푸터 레이아웃(Footer Layout) 설정에 대하여그리드 하단의 합계와 요약 정보를 구성할 수 있습니다.
  6. 자주 찾는 문서AUIGrid 속성, 메소드, 이벤트 설정에 대하여 (개발 API 문서)기능별 설정값과 API 사용 방법을 찾아볼 수 있습니다.
  7. React, Vue 및 TypeScript에서 사용하기프레임워크별 예제와 서브 컴포넌트 속성을 확인할 수 있습니다.
  8. AI 개발 지원: AUIGrid MCP ServerAI 개발 도구에서 공식 문서와 예제를 활용할 수 있습니다.
  9. 비상업용 CDN으로 시작하기로컬 환경에서 비상업용 버전을 실행할 수 있습니다.

칼럼 레이아웃에서 정의할 수 있는 항목은 칼럼 레이아웃 속성에서 확인할 수 있습니다.

칼럼 레이아웃으로 그리드를 생성하고 추가 속성을 설정하는 방법은 그리드 생성 시 설정하는 속성 및 메소드 리스트에서 확인할 수 있습니다.
