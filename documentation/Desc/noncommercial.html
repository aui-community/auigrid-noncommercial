9. 비상업용 CDN으로 시작하기

AUIGrid는 비상업용 버전(Non-Commercial)의 CDN을 제공합니다. 처음 그리드를 만들어 보거나 학습, 연구 및 기능을 평가할 때 무료로 시작할 수 있습니다.

CDN은 비상업용 버전에만 제공하며, 정품은 CDN으로 제공하지 않습니다. 정품은 제공받은 제품 파일을 프로젝트에 배치하여 사용합니다.

CDN을 이용하면 라이브러리를 직접 내려받아 배치하는 과정 없이 HTML에 연결하여 그리드를 만들 수 있습니다. 칼럼과 데이터를 바꾸며 정렬, 필터 및 편집 기능을 직접 확인하고, AI 개발 도구와 함께 원하는 예제로 확장해 보십시오.

비상업용 GitHub 저장소 | CDN 시작 예제 HTML 내려받기 | AI 개발 지원: AUIGrid MCP Server

시작 방법CDN 연결예제 실행 React, Vue 및 TypeScriptAI와 함께 사용사용 조건다른 서버에서 평가하기

9.1 원하는 방법으로 시작하기

방법활용
비상업용 CDNHTML에 JavaScript와 CSS 주소를 연결하여 빠르게 실행합니다. 파일을 불러올 때 인터넷 연결이 필요합니다.
GitHub 다운로드라이브러리, 테마, 문서와 JavaScript 및 React/Vue 샘플을 내려받아 로컬 프로젝트에서 사용합니다.
평가판 다운로드localhost 이외의 접속 도메인이나 IP를 사용하는 테스트 서버에서 기능을 확인합니다. 아래 평가판 안내를 참고하십시오.
MCP 연결AI가 공식 API와 실제 예제를 조회하여 설치와 코드 작성을 돕습니다. 실행 파일은 CDN 또는 다운로드로 준비합니다.

비상업용 버전은 비상업용 목적의 localhost 또는 127.0.0.1 환경에서 사용합니다. 같은 제품 버전의 상용 라이선스와 기능적 차이는 없으며, 자세한 조건은 사용 조건을 확인하십시오.

9.2 CDN 연결

HTML의 <head>에 라이선스, 엔진 및 테마 CSS를 연결합니다. 다음 주소는 비상업용 GitHub 저장소의 dist 파일을 jsDelivr CDN으로 제공합니다.

<!-- 비상업용 라이선스 -->
<script src="https://cdn.jsdelivr.net/gh/aui-community/auigrid-noncommercial@main/dist/AUIGridLicense.js"></script>
<!-- AUIGrid 실행 엔진 -->
<script src="https://cdn.jsdelivr.net/gh/aui-community/auigrid-noncommercial@main/dist/AUIGrid.js"></script>
<!-- 기본 테마: CDN의 스타일 규칙도 읽을 수 있도록 crossorigin을 지정합니다. -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/aui-community/auigrid-noncommercial@main/dist/AUIGrid_style.css" crossorigin="anonymous">

CDN은 라이브러리를 전달하는 방법입니다. 예제 페이지는 로컬 웹 서버에 두고 http://localhost:포트/ 또는 http://127.0.0.1:포트/로 접속합니다.

9.3 HTML 하나로 실행해 보기

  1. CDN 시작 예제를 내려받아 빈 폴더에 index.html로 저장합니다.
  2. 에디터의 로컬 웹 서버나 사용 중인 개발 서버로 해당 폴더를 실행합니다.
  3. 브라우저에서 http://localhost:포트/index.html 또는 http://127.0.0.1:포트/index.html을 엽니다.
  4. 헤더를 클릭하여 정렬하고 필터 아이콘으로 데이터를 고릅니다. 셀을 더블클릭하여 값을 편집합니다.

예를 들어 Python이 설치되어 있다면 예제 폴더에서 python -m http.server 8000 --bind 127.0.0.1을 실행하고 http://127.0.0.1:8000/index.html을 엽니다. 로컬 서버 도구는 원하는 것을 사용해도 됩니다.

예제에 데이터가 포함되어 있어 별도의 데이터 파일이나 API 서버를 준비할 필요가 없습니다. columnLayout에서 칼럼을, rows에서 데이터를 바꾸어 보십시오. 작성 흐름은 Quick Start와 데이터 구조 안내에서 이어서 확인할 수 있습니다.

9.4 React, Vue 및 TypeScript에서 사용하기

GitHub에는 samples-React.js, samples-React.tsx, samples-Vue.js, samples-Vue.ts의 네 샘플 프로젝트와 래퍼가 포함되어 있습니다. 해당 샘플은 로컬 파일을 import하는 구조이므로 프레임워크 샘플 실행 안내에 따라 시작하십시오.

npm의 aui-grid는 TypeScript 타입 정의와 enum을 제공합니다. 그리드를 실행하는 엔진, 라이선스 및 CSS는 비상업용 배포본이나 사용 환경에 맞는 제품 배포본에서 준비합니다.

9.5 AI와 함께 예제 만들기

AI 개발 도구에 https://auigrid.com/mcp를 Streamable HTTP로 등록하면 인증 없이 공개 문서와 예제를 읽기 전용으로 조회할 수 있습니다. 주소 끝에 슬래시를 붙이지 않습니다. 원격 연결에는 Node.js나 MCP 패키지를 설치할 필요가 없습니다. 도구별 원격 연결 안내에 따라 연결한 뒤 다음과 같이 요청할 수 있습니다.

AUIGrid 비상업용 CDN 시작 안내를 찾아줘. localhost에서 실행할 수 있게, 데이터가 포함된 HTML 하나로 정렬, 필터 및 편집이 가능한 그리드를 만들어줘.

MCP의 search_docs에서 CDN, 비상업용, 무료, 시작하기로 검색하면 이 안내를 찾을 수 있습니다. get_api에 id: "Desc/noncommercial.html"을 전달하면 본문과 사용 조건을 조회합니다.

list_examples의 query: "CDN"으로 실행 예제를 찾고, get_example의 id: "noncommercial-cdn-vanilla-js"로 전체 HTML을 가져올 수 있습니다. 별도 데이터 파일이나 WebDemo의 PHP 공통 파일 없이 실행할 수 있는 예제입니다.

React 또는 Vue 프로젝트라면 프레임워크와 JavaScript/TypeScript 사용 여부를 함께 알려 해당 샘플과 래퍼를 참고하도록 요청하십시오.

9.6 비상업용 버전의 사용 조건

비상업용 목적의 localhost 및 127.0.0.1 환경에서 기간 제한 없이 사용할 수 있습니다. 교육, 학술, 연구, 개인 용도와 비상업적 평가, 개발 및 테스트에 활용할 수 있습니다.

기업 직원도 상업적 운영 환경이 아닌 로컬 환경에서 평가, 개발 및 테스트 목적으로 사용할 수 있습니다. 다른 서버의 도메인이나 IP에서 기능을 확인하려면 아래의 평가판을 이용할 수 있습니다. 상업적 서비스나 운영 환경에서 사용하려면 해당 환경에 맞는 상용 라이선스가 필요합니다.

세부 허용 및 금지 사항은 비상업용 배포 안내와 라이선스 원문을 확인하십시오. 상용 이용은 AUISoft로 문의할 수 있습니다.

9.7 다른 서버에서 확인하려면 평가판을 이용해 보세요

로컬에서 만든 그리드를 사내 테스트 서버에 올리거나, 다른 PC나 모바일 기기에서 접속해 확인하고 싶으신가요? localhost 및 127.0.0.1 이외의 도메인이나 IP를 사용하는 환경에서는 AUIGrid 평가판 다운로드를 이용해 보십시오.

평가판은 정품과 같은 기능을 제공하며, 다운로드한 날부터 30일 동안 무료로 사전 평가, 프로젝트 적합성 검토(PoC) 및 테스트에 사용할 수 있습니다.

  1. 평가판 다운로드 페이지에서 제품으로 AUIGrid를 선택합니다.
  2. 접속 도메인 항목에 테스트할 서버의 도메인이나 IP를 입력합니다. 최대 4개까지 지정할 수 있습니다.
  3. 회사 또는 기관명, 이름, 이메일과 페이지의 약관 및 동의 항목을 확인한 뒤 평가판을 내려받습니다.
  4. 평가판에 포함된 엔진, 라이선스 및 CSS를 프로젝트에 배치하고, 입력한 도메인이나 IP로 접속하여 확인합니다. CDN 비상업용 파일을 연결했던 예제는 평가판 파일을 불러오도록 경로를 바꿉니다.

예를 들어 접속 주소가 http://test.mydomain.com:8080이라면 test.mydomain.com만 입력합니다. IP로 접속한다면 해당 IP만 입력하며 http://, https://, 포트 번호와 페이지 경로는 제외합니다.

평가 기간이 끝나면 평가판 라이선스도 만료됩니다. 프로젝트에 적합한지 확인한 뒤 실제 개발 및 운영에 사용할 제품은 AUISoft의 정품 구매 안내를 참고하십시오. 자세한 평가판 이용 조건은 다운로드 페이지에서 확인할 수 있습니다.
