플러그인 공통 런타임

Pivot 및 Gantt 플러그인의 제공이 보류되어 공통 런타임의 외부 접근은 현재 비활성화되어 있습니다. 제공 일정은 미정입니다.

현재 동작

AUIGrid.getPluginRuntime(1)을 포함한 모든 호출은 code: "AUI_GRID_PLUGIN_RUNTIME_DISABLED"인 Error를 발생시킵니다. 공통 클래스나 함수의 참조는 반환하지 않으며 그리드 설정, 전역 변수 또는 주소의 옵션으로 활성화할 수 없습니다.

메소드 이름과 연결 계약의 선언은 제공 재개를 위해 보존합니다. 선언이 있거나 메소드가 함수로 확인되는 것만으로 플러그인을 사용할 수 있다고 판단해서는 안 됩니다.

일반 AUIGrid와 사용자 정의 렌더러는 기존 방식으로 사용합니다.
